核心聊天功能覆盖主流 IM 需求，支持一对一私聊、多人群组聊天，可发送文字、表情、图片、语音、短视频、文件等富媒体消息，支持消息撤回、已读状态、消息引用、转发、会话置顶、消息免打扰。自带好友体系，支持搜索用户、发送好友申请、备注管理、黑名单功能。同时支持离线消息缓存，用户上线后自动拉取历史聊天记录，搭配厂商推送，APP 退出后台也能收到消息提醒。

后台管理模块功能齐全，可管理用户账号、审核用户、管控群组、查看在线人员、统计消息数据。支持权限分级，管理员可分配不同后台操作权限，方便团队协同管理。还可对接自有业务系统，和商城、社区、客服平台打通，作为内置聊天模块使用。
